# JavaScript - DOM Manipulation

This project focuses on learning the basics of DOM (Document Object Model) manipulation in JavaScript, including element selection, event handling, updating styles, and toggling CSS classes.

---

## 📁 Repository Structure

* **Repository:** `holbertonschool-higher_level_programming`
* **Directory:** `javascript-dom_manipulation`

---

## 📝 Tasks Overview

| # | Task | File | Description |
| :-: | :--- | :--- | :--- |
| **0** | **Color Me** | `0-script.js` | Updates `<header>` text color to red (`#FF0000`) using `document.querySelector`. |
| **1** | **Click and turn red** | `1-script.js` | Updates `<header>` text color to red when `#red_header` is clicked. |
| **2** | **Add .red class** | `2-script.js` | Adds the `red` class to `<header>` when `#red_header` is clicked. |
| **3** | **Toggle classes** | `3-script.js` | Toggles `<header>` class between `red` and `green` when `#toggle_header` is clicked. |

---

## 💻 How to Test

1. Open the target HTML file (e.g., `0-main.html`, `1-main.html`) in any modern web browser.
2. Interact with the page elements to observe DOM updates based on the script logic.
